# GitAura

自用的桌面端 Git 客户端，扁平化界面、暗色优先、纯中文，AI 能力规划中。

基于 Tauri 2 + Vue 3，通过 shell 调用系统 git。

## 功能范围（MVP）

- 多仓库标签页
- 拉取 / 推送
- 分支管理（新建 / 检出 / 删除 / 重命名 / 合并 / 对比）
- cherry-pick
- 暂存区（文件级 + hunk 级）
- 提交
- 更改阅读（diff：统一 / 双栏 / 词级高亮）
