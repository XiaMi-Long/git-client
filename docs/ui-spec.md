# Git 客户端 UI 规范

> 基于设计语言文档，规定具体界面元素与交互的落地规范。
> 创建日期：2026-07-29 · 维护者：本人
> 上游依据：[设计语言](./design-language.md)

## 1. 全局布局

### 1.1 主窗口结构

```
┌─────────────────────────────────────────────────────────┐
│ 顶栏 (40px)                                              │
├──────────┬──────────────────────┬───────────────────────┤
│          │                      │ 文件列表区            │
│ 侧栏      │   提交列表            │   (高 40%，可拖拽)    │
│ (220px)  │   (自适应)            ├───────────────────────┤
│ 可拖拽    │                      │ diff 区               │
│ 160-360  │                      │   (占剩余)            │
├──────────┴──────────────────────┴───────────────────────┤
│ 状态栏 (24px)                                            │
└─────────────────────────────────────────────────────────┘
```

尺寸规范：

- 顶栏：固定 40px
- 状态栏：固定 24px
- 侧栏：默认 220px，可拖拽范围 160–360px
- 提交列表：自适应，最小 280px
- 文件列表区：默认占右侧 40%，可拖拽 20%–70%
- diff 区：占右侧剩余空间
- 分隔条：1px，hover 时 `--border-strong`，拖拽时显示 1px 主色预览线

### 1.2 仓库标签页

- 位于顶栏左侧，每个标签显示仓库名
- 当前标签高亮（`--bg-panel` 底 + 主色下边框 2px）
- 标签可关闭（× hover 显示）
- 末尾 [+] 打开新仓库

## 2. 组件规范

### 2.1 按钮

| 类型 | 样式 | 用途 |
|---|---|---|
| 主按钮 | 主色填充，白字 | 提交、确认 |
| 次按钮 | 透明底 + 1px 边框 | 取消暂存、关闭 |
| 文字按钮 | 无边框，hover 浅底 | 列表内行级操作 |

- 高度：28px（常规）/ 24px（紧凑）
- 内边距：左右 12px
- 圆角：2px
- 禁用：opacity 0.4，不响应

### 2.2 输入框

- 高度：28px
- 背景：`--bg-input`
- 边框：1px `--border-default`，聚焦 `--accent`
- 占位符：`--fg-tertiary`
- 圆角：2px

### 2.3 列表项

- 高度：26px（提交列表 / 文件列表）
- hover：`--bg-elevated`
- 选中：`--accent` 透明度 0.15 背景 + 左侧 2px 主色条
- 内边距：左右 8px

### 2.4 树节点（侧栏分支 / 标签）

- 缩进：每级 12px
- 展开箭头：▶ / ▼，10px
- 当前分支：节点为主色实心圆 + 加粗
- 远程分支：节点为空心圆，文字带 `origin/` 前缀灰色

### 2.5 标签（分支 / 标签徽章）

- 背景：语义色透明度 0.15
- 文字：语义色
- 圆角：2px
- 内边距：2px 6px

### 2.6 文件状态标识

- 等宽单字母：M / A / D / R / ?
- 颜色按设计语言 §8
- 固定宽度，左对齐于文件名前

### 2.7 diff 视图

- 行号：右对齐，`--fg-tertiary`，等宽，固定列宽
- hunk 头：`@@ ... @@`，`--diff-hunk-bg` 背景
- 新增行：`--diff-add-bg` 背景
- 删除行：`--diff-del-bg` 背景
- 词级高亮：`--diff-word-bg` 背景
- 等宽字体，默认不自动换行（可手动开 Wrap）
- 统一视图 / 双栏视图切换按钮在 diff 区右上角

### 2.8 提交列表项

- 单行：mini 图谱列 + 哈希（等宽，`--fg-tertiary`，7 位短哈希）+ 提交信息 + 作者 + 相对时间
- 选中：见 §2.3
- 带分支 / 标签徽章：提交信息右侧

### 2.9 状态栏

- 高 24px，`--bg-base`，字号 12px
- 左：连接状态 + 远程分支名
- 中：领先 / 落后计数（领先绿、落后黄）
- 右：编码 · 刷新状态

## 3. 交互规范

### 3.1 右键菜单

- 统一组件，`--bg-elevated` 底 + 阴影（见设计语言 §6）
- 项高 28px，hover `--bg-panel`
- 分隔线 1px `--border-default`
- 危险项（删除）：`--danger` 文字

### 3.2 鼠标行为

| 对象 | 单击 | 双击 | 右键 |
|---|---|---|---|
| 侧栏分支 | 浏览该分支历史 | 检出 | 分支操作菜单 |
| 提交项 | 选中并显示其更改 | — | cherry-pick / 建分支 / 检出 / 重置 / 复制哈希 |
| 文件项（工作区） | 选中显示 diff | — | 暂存 / 取消暂存 / 丢弃 |
| diff hunk | — | — | 暂存此块 / 丢弃此块 |

### 3.3 快捷键

| 快捷键 | 功能 |
|---|---|
| Ctrl+Enter | 提交（工作区模式） |
| Ctrl+P | 拉取 |
| Ctrl+Shift+P | 推送 |
| F5 | 刷新当前仓库 |
| Ctrl+K | 聚焦搜索 |
| Esc | 关闭 popover / 菜单 |

### 3.4 防抖

- 搜索输入：300ms
- 文件系统监听刷新：500ms
- 分隔条拖拽：实时，无防抖

## 4. 状态规范

| 状态 | 表现 |
|---|---|
| 加载中 | 列表区骨架屏（灰条占位）；按钮转圈图标 |
| 空状态 | 居中图标 + 一句中文说明 +（可选）引导按钮 |
| 错误 | 顶部红条 `--danger` + 错误文案 + 重试按钮 |
| 冲突 | 文件项 ⚠ 标记；状态栏显示 [继续] [中止] |
| 操作进行中 | 状态栏显示进行中文案 + 转圈；相关按钮禁用 |

## 5. 文案规范

统一中文术语，不混用英文：

| 统一用 | 不用 |
|---|---|
| 拉取 | pull |
| 推送 | push |
| 暂存 | stage / add |
| 取消暂存 | unstage |
| 提交 | commit |
| 检出 | checkout |
| 合并 | merge |
| 变基 | rebase |
| 暂存区 | staging area |
| 工作区 | working area |
| 分支 | branch |
| 标签 | tag |
| 远程 | remote |
| 领先 / 落后 | ahead / behind |

例外：哈希、命令名、文件路径保持原样。
