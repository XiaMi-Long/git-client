# Git 客户端设计语言

> 本文档定义本项目统一的视觉设计语言，是所有界面实现与后续迭代的基线。
> 风格定位：扁平化 · 暗色优先 · 信息密度高 · 工具型 · 纯中文。
> 创建日期：2026-07-29 · 维护者：本人

## 1. 设计理念

| 原则 | 说明 |
|---|---|
| 扁平化 | 去除渐变、拟物、冗余阴影；用色彩与排版建立层次 |
| 信息密度优先 | 工具型应用，单位面积承载更多有效信息优于留白美学 |
| 色彩克制 | 中性灰为基调，语义色仅用于状态点睛，避免高饱和 |
| 一致性 | 相同操作给相同反馈，相同数据用相同呈现 |
| 高效可达 | 常用操作键盘可达，点击数最小化 |
| 静稳 | 列表与面板不使用装饰性动画；动效仅用于状态反馈 |

## 2. 色彩系统

### 2.1 暗色主题（默认）

背景层次（由深到浅）：

- `--bg-base: #1e1e1e` 应用最底层
- `--bg-panel: #252526` 面板 / 侧栏 / 列表区
- `--bg-elevated: #2d2d30` 悬浮层 / popover / 选中项
- `--bg-input: #2a2a2d` 输入框内底色

前景文字：

- `--fg-primary: #e8e8e8` 主文字
- `--fg-secondary: #a0a0a0` 次要文字 / 说明
- `--fg-tertiary: #6a6a6a` 占位 / 禁用

边框 / 分隔：

- `--border-default: #3c3c3c`
- `--border-strong: #555555` 聚焦 / 拖拽

语义色：

- `--accent: #3b82f6` 主色，操作 / 选中
- `--accent-hover: #4a90f7`
- `--success: #4ec9b0` 已提交 / 干净 / 领先
- `--warning: #dcdcaa` 未提交 / 落后提醒
- `--danger: #f48771` 冲突 / 删除 / 错误
- `--info: #569cd6` 远程 / 分支引用

### 2.2 diff 专用色

- `--diff-add-bg: #1e3a1e` 新增行背景
- `--diff-add-fg: #4ec9b0` 新增行文字
- `--diff-del-bg: #3a1e1e` 删除行背景
- `--diff-del-fg: #f48771` 删除行文字
- `--diff-hunk-bg: #2a2a3a` hunk 头背景
- `--diff-word-bg: #5a5a2e` 词级改动高亮

### 2.3 亮色主题（可切换）

亮色为暗色的语义映射，保持语义一致：

- `--bg-base: #ffffff`
- `--bg-panel: #f8f8f8`
- `--bg-elevated: #ffffff`
- `--fg-primary: #1e1e1e`
- `--fg-secondary: #5a5a5a`
- `--fg-tertiary: #9a9a9a`
- `--border-default: #e0e0e0`
- `--border-strong: #bdbdbd`
- `--accent: #2563eb`
- diff 色：增 `#e6f4e6` / `#1a7d1a`；删 `#fde8e8` / `#c0392b`；词级 `#fff3bf`

## 3. 字体系统

| 用途 | 字族 | 字号 | 行高 |
|---|---|---|---|
| UI 文字 | "Microsoft YaHei UI", "Segoe UI", system-ui, sans-serif | 13px | 1.4 |
| 等宽（代码 / diff / 哈希 / 路径） | "Cascadia Code", "JetBrains Mono", Consolas, monospace | 13px | 1.5 |

字号阶梯：12（辅助）/ 13（正文）/ 14（小标题）/ 16（区段标题）/ 20（页面标题）

字重：400 正文 / 500 强调 / 600 标题。不使用 700+，保持扁平克制。

## 4. 间距与栅格

- 基准单位：4px
- 常用阶梯：4 / 8 / 12 / 16 / 24 / 32
- 组件内 padding：8px（默认）/ 4px（紧凑列表项）
- 区块间距：16px

## 5. 圆角与边框

- 输入框 / 按钮：2px
- 卡片 / 面板内嵌块：4px
- 列表项 / 分隔条 / 树节点：0（直角，保证密度）
- 边框统一 1px solid

## 6. 阴影与层次

扁平化原则下极少使用阴影：

- 默认面板 / 列表：无阴影，用 1px 边框 + 背景色差区分层次
- 仅 popover / dropdown / context-menu：`0 2px 8px rgba(0,0,0,0.3)`
- 拖拽分隔条 / 悬浮预览：用边框高亮，不用阴影

## 7. 动效

- 时长：150ms（状态切换）/ 0ms（列表渲染、面板尺寸拖拽）
- 缓动：ease
- 范围：仅颜色 / 透明度过渡；不做位移 / 缩放动画
- 禁止：列表项进出动画、页面切换转场动画

## 8. 图标语言

- 风格：线性（stroke），描边 1.5px，尺寸 16px
- 颜色：继承当前文字色；语义图标用语义色
- 来源：统一一套图标集（推荐 Lucide），不混用
- 文件状态字母：M（橙）/ A（绿）/ D（红）/ R（蓝）/ ?（灰），等宽单字母

## 9. 提交图谱（mini graph）视觉

- 列宽：20px 等宽
- 节点：直径 8px 圆点，颜色按分支区分
- 连线：1.5px 贝塞尔曲线，颜色与节点匹配
- 当前 HEAD：节点带主色环

## 10. 主题 Token 落地

所有色彩通过 CSS 变量定义在 `:root`（暗色）与 `[data-theme="light"]`（亮色）。组件只引用变量，不硬编码颜色。新增界面必须从设计语言取 token，不得引入未在本文档定义的颜色值。
