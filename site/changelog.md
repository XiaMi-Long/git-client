# 更新日志

## 下载与自动更新

GitTrail 通过 **GitHub Releases + 自动更新** 分发：

- 下载安装包：[GitHub Releases](https://github.com/XiaMi-Long/git-client/releases)
- 已安装版本会在启动后静默检查新版本，下载完成后提示重启；也可在 **设置 → 关于 → 检查更新** 手动检查。
- 更新包均带**数字签名**，自动更新会校验签名，防止伪造更新。

> 更新日志以各版本 Release 说明为准，这里记录主要里程碑。

## 版本历史

### v0.1.0（MVP）

首个可用版本，覆盖本地高频 Git 操作：

- **多仓库标签页**：同时打开多个仓库，状态独立，重启恢复。
- **分支管理**：新建 / 检出 / 删除 / 重命名 / 合并 / 对比，切换自动暂存。
- **暂存与提交**：文件级 + hunk 级暂存，快捷提交。
- **diff 阅读**：统一 / 双栏 / 词级高亮。
- **cherry-pick**：右键挑选提交。
- **冲突处理**：冲突标记与解决引导。
- **主题**：暗色优先，明暗切换。
- **自动更新**：GitHub Releases + 签名校验静默升级。

### 开发中（feat/commit-swimlane-v2）

- **提交泳道图 V2**：行 = 提交、列 = 作者，当前用户置顶 + 频率排序，点击列头过滤，列宽可拖拽，行虚拟滚动。
- **未推送标识**：本地领先上游的提交显示「未推送」徽章（经典列表 / 泳道图一致）。
- **自定义标题栏**：无边框窗口 + 自绘标题栏（最小化 / 最大化 / 关闭，拖拽与双击最大化），软件名称统一为 **GitTrail**。

> 更新日志以各版本 Release 说明为准。
