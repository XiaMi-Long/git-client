# 功能一览

GitTrail 面向本地高频 Git 操作，功能聚焦、克制、纯中文。

## 多仓库标签页

- 同时打开多个仓库，顶部横向标签快速切换，仓库状态互不影响。
- 标签支持关闭、横向滚动；切换仓库即自动恢复各自的分支与浏览状态。
- 已打开仓库路径本地持久化，重启自动恢复。

## 分支管理

- 侧栏展示本地 / 远程分支与标签，当前分支高亮。
- 支持 **新建 / 检出 / 删除 / 重命名 / 合并 / 对比**，右键直达。
- 切换分支前自动暂存未提交更改，避免丢失。
- 支持从远程分支创建本地分支（`origin/xxx` → 本地）。

## 提交历史

- **经典列表**：mini 分支图谱 + 哈希 + 提交信息 + 作者 + 相对时间，虚拟滚动，海量提交流畅。
- **泳道图（V2）**：行 = 提交，列 = 作者泳道；当前用户置顶、按提交频率排序；点击列头过滤该作者；列宽可拖拽；时间列可调宽。
- **未推送标识**：本地领先上游的提交带绿色「未推送」徽章，两种视图一致。
- 远程落后提示：当前分支落后上游时显示提示行，点击展开远程待拉取提交列表。

## 暂存与提交

- 工作区 / 暂存区 / 未跟踪 / 冲突分类展示。
- **文件级 + hunk 级**暂存：支持暂存、取消暂存、丢弃单个文件或整个 hunk。
- 提交框（工作区模式）：输入提交信息，`Ctrl+Enter` 快速提交。
- 冲突处理：冲突文件标记、逐个标记已解决，支持中止操作恢复。

## diff 阅读

- **统一 / 双栏 / 词级高亮**三种视图。
- hunk 头、新增 / 删除行、词级改动高亮，行号对齐，等宽字体。
- 支持右键对单个 hunk 暂存或丢弃。

## cherry-pick

- 提交列表右键 **cherry-pick**，无需切分支。
- **压缩挑拣**（squash pick）：把多次提交压缩为一个再应用。
- cherry-pick 冲突可继续 / 中止，有完整引导。

## 储藏（stash）

- 支持储藏未暂存 / 暂存 / 全部，命名储藏。
- 查看、应用、删除储藏；可从储藏查看 diff。

## 拉取 / 推送

- 工具栏一键拉取 / 推送（`Ctrl+P` / `Ctrl+Shift+P`）。
- 推送支持 `--set-upstream` 建立上游；远程删除分支。
- 窗口聚焦自动刷新，后台定时 fetch 更新领先 / 落后计数。

## 主题与体验

- **暗色优先**，明暗一键切换并持久化。
- 全局进度条 + Toast 提示 + 统一确认 / 弹窗。
- 快捷键：`Ctrl+P` 拉取、`Ctrl+Shift+P` 推送、`Ctrl+Enter` 提交、`F5` 刷新、`Ctrl+K` 聚焦搜索。
- 启动静默检查更新，新版本下载完成后提示重启。

## 技术栈

| 层 | 技术 |

| 桌面壳 | Tauri 2 |
