## Why

提交列表适合精确查找，作者泳道适合观察贡献者分布，但用户仍难从提交顺序中看清分支合并、单个文件的演进、版本范围和长期活动趋势。新增互补的历史视图，并让切换时保留仓库范围、提交选择和各视图浏览位置，可让用户围绕同一份 Git 历史选择合适的阅读方式。

## What Changes

- 增加分支拓扑图、文件/目录历史、版本标签时间线和近半年提交活动热力图。
- 在经典列表中支持按日期分组；保留已有作者泳道和经典列表。
- 将图标式二态切换改为有名称和用途说明的多视图选择器。
- 各提交视图共用提交选择；适用的视图共用当前分支/所有分支范围，版本视图使用显式标签范围；切换后保留当前提交、筛选条件和各视图滚动位置。
- 支持从活动日期及版本标签进入对应提交，并继续使用现有提交文件和 diff 面板。
- 为文件历史增加路径范围日志查询，为活动热力图增加按日聚合查询；不改变仓库数据。

## Capabilities

### New Capabilities
- `commit-history-exploration`: 多种提交历史浏览方式、统一的视图切换，以及视图间的筛选和选择状态衔接。

## Impact

- 前端提交历史工具栏、设置、提交状态 store、提交列表和泳道图，以及新增的历史视图组件。
- Tauri Git 日志查询参数增加可选路径和拓扑排序；新增指定时间范围的按日提交活动聚合命令。
- 复用现有标签、提交详情、文件差异和分支范围接口；不增加外部依赖。
