# Local fonts

The WOFF2 files in this directory are Latin subsets downloaded from Google Fonts for offline use by the GitTrail desktop UI.

- Archivo: https://fonts.google.com/specimen/Archivo
- IBM Plex Mono: https://fonts.google.com/specimen/IBM+Plex+Mono
- Parisienne: https://fonts.google.com/specimen/Parisienne

All three families are distributed under the SIL Open Font License 1.1:
https://openfontlicense.org/open-font-license-official-text/

Keep the license terms with the font files when redistributing the application.
